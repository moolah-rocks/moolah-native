Set a budget for an earmark

Plan how an earmark's money breaks down across categories, then track actual spending against the plan from the earmark's Budget tab.

Before you start

  • You need an existing earmark. If you haven't created one yet, see Create an earmark.
  • You need the categories you want to budget against. If you haven't set them up yet, see Create and organise categories.

Add a budget line item

  1. Open the earmark from the Earmarks section of the sidebar.
  2. Select the Budget tab.
  3. In the toolbar, select Add Budget Line Item (the + button).
  4. In the Category field, start typing and choose a category from the suggestions.
  5. In the Budget Amount field, enter how much you plan to spend on that category.
  6. Select Save.

Repeat for each category you want to budget. One earmark can hold as many line items as you need.

Edit a line item

  1. In the Budget tab, select the amount in the Budget column for the line item you want to change.
  2. Enter the new amount.
  3. Select Save.

Remove a line item

  1. In the Budget tab, find the line item.
    • On a Mac, right-click the row and choose Delete.
    • On iPhone or iPad, swipe the row left and tap Delete.
  2. Confirm the deletion. The transactions in that category stay where they are; only the budget plan goes away.

Reading the Budget tab

Each row shows four columns:

  • Category — the category this line item covers.
  • Actual — what you've spent in that category against this earmark so far.
  • Budget — the amount you planned. Select this cell to edit.
  • Remaining — budget minus actual. Negative when you've gone over.

The Total row at the bottom sums all line items. If transactions assigned to the earmark fall outside the budgeted categories, an Unallocated row shows how much.

Result

The Budget tab now tracks planned versus actual spending for each category you added, and the figures update as you assign transactions to the earmark.
