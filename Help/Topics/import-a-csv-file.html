Import a CSV file

Bring transactions into Moolah from a CSV file you've downloaded or copied. This article covers every route the app offers.

Before you start

  • Export the CSV from your bank, brokerage, or other source. Most banks have a "download transactions" option.
  • Have the account you want to import into ready in Moolah. See Add an account if you haven't created one yet.

Import from the File menu (Mac)

  1. Choose File > Import CSV, or press ⇧⌘I.
  2. Select the CSV file.

Moolah opens Recently Added with the imported transactions.

Drag a file onto the window

  1. Drag a CSV file from Finder.
  2. Drop it on the Moolah window, or drop it directly on an account in the sidebar to pre-select that account.

Paste tabular text (Mac)

Use this when you've selected rows in a spreadsheet or copied a table from a webpage.

  1. Copy the rows to the clipboard.
  2. In Moolah, choose File > Paste CSV, or press ⌥⇧⌘V.

Import on iOS

  1. In the Files app, tap and hold the CSV file.
  2. Choose Share, then pick Moolah from the share sheet.

Alternatively, drag the CSV file from another app and drop it directly on Moolah.

When the file shape is new

The first time you import a file from a new source, Moolah may not recognise its layout. The file lands in Recently Added under Needs Setup. Open the row, choose Set up CSV import, pick the target account, and map each column (Date, Description, Amount, Payee). Moolah remembers the layout and imports future files of the same shape without asking. See How CSV import works for what gets remembered.

Result

The imported transactions appear in Recently Added, ready for you to review. Any import rules you've set up have already been applied. See Review recently imported transactions for what to do next.
