Create and organise categories

Manage your category list: add, edit, reorganise, and delete categories, including what happens to transactions when a category is removed.

Add a category

  1. In the sidebar, select Categories.
  2. On Mac, select + in the toolbar, or press ⌥⌘N. On iOS, select + at the top of the list.
  3. Enter a name.
  4. If you want an icon, pick one from the icon picker.
  5. To nest this category under another, set Parent to the category you want it to live under. Leave Parent empty to keep it at the top level.
  6. Select Save.

Edit a category

  1. In the Categories list, select the category you want to change.
  2. On Mac, edit fields in the inspector. On iOS, the detail sheet opens automatically.
  3. Change the name, icon, or parent. Setting or clearing Parent moves the category in the tree.

Changes apply to every transaction already using the category. You don't need to retag anything.

Move a category to a different parent

  1. In the Categories list, select the category you want to move.
  2. On Mac, edit the Parent field in the inspector. On iOS, the detail sheet opens.
  3. Choose a new parent from the picker, or clear the field to move it to the top level.
  4. Select Save.

Delete a category

  1. In the Categories list, select the category you want to delete.
  2. Select Delete.
  3. If transactions still use this category, Moolah asks where to put them. Pick another category to reassign them to, or leave them uncategorised.
  4. Confirm the deletion.

Deleting a category is permanent. The transactions themselves stay where they are — only their category assignment changes.

If the category has child categories under it, you'll need to move or delete the children first.

Result

The category list reflects your changes immediately, and any reports and budgets that use these categories update with the new structure.
