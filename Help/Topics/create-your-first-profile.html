Create your first profile

A profile holds all your accounts, transactions, categories, and earmarks. This article walks through creating one from a fresh install.

Before you start

  • Install Moolah from the App Store and launch it.
  • If you want to sync between devices, sign in to iCloud on each device first. You can skip this and turn on sync later.

What the Welcome screen shows

The Welcome screen tells you what Moolah found when it looked at iCloud:

  • Checking iCloud… — Moolah is still looking. You can create a profile without waiting.
  • iCloud is not signed in (or restricted, or unavailable) — sync is off; you can still create a local profile. See iCloud says it's off.
  • No profiles found in iCloud — nothing to download; create a new one.
  • We found N profiles — there are profiles on another of your devices. To open one instead, see Pick up a profile on another device.

Steps

  1. On the Welcome screen, select Get started.
  2. In the Name field, enter a label for the profile (for example, "Personal" or your name).
  3. (Optional) Expand Advanced to adjust the profile's defaults:
    • Currency — defaults to your device's currency. Moolah uses this currency for all totals.
    • Financial year starts — defaults to July. Reports such as "This Financial Year" use this month as the boundary.
  4. Select Create Profile.

Result

The new profile loads and becomes active. On Mac, a window opens for it. The sidebar is empty — no accounts, no transactions yet. From here, the usual next step is to add an account.
