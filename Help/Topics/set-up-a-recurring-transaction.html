Set up a recurring transaction

Configure a transaction to repeat on a schedule — useful for rent, subscriptions, payday, or any other regular money movement. A recurring transaction is a scheduled transaction with a Recurrence other than Once. To set up recurrence on an existing transaction, open it instead and skip to step 4.

Steps

  1. Select + in the toolbar. On Mac, you can also press ⌘N.
  2. Fill in the usual fields: amount, account, category, payee, and any notes.
  3. Set the Date to the next time the transaction should occur. This is the first scheduled occurrence, so use a future date.
  4. In the transaction detail, scroll to the Recurrence section.
  5. Choose how often it repeats: Day, Week, Month, or Year.
  6. Set the multiplier — the "every N" number. For example, choose Week with 2 for a fortnightly transaction.
  7. Save the transaction.

Moolah describes the recurrence back to you in plain English, like "Every 2 weeks" or "Every month". If the description doesn't match what you intended, adjust the period or the multiplier.

Changing the recurrence later

To change how often a recurring transaction repeats, open it from the Scheduled list and edit the Recurrence section. The change applies to all future occurrences, not to anything you've already paid.

Stopping recurrence

To stop a transaction from repeating, open it and set Recurrence to Once. The next occurrence stays scheduled, but no further ones will be generated after you pay it.

Result

The transaction appears in the Scheduled sidebar item with its recurrence shown next to it, and feeds into the Upcoming and Analysis forecasts.
