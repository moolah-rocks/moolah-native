My wallet or exchange account isn't syncing

The synced-account header at the top of a Crypto Wallet or Exchange account shows a caption explaining why. Match the caption to the section below.

The API key or token is missing

For a wallet, the caption reads Add an Alchemy API key to enable sync. For a Coinstash exchange account, it reads Add your read-only API token to sync.

For a crypto wallet:

  1. Open Settings > Crypto Tokens.
  2. Paste your Alchemy API key. (On Mac, the inline hint links straight to this screen.)

For an exchange account:

  1. Open the account.
  2. Choose Edit Account and paste your read-only Coinstash API token.

Sync starts on its own once the key or token is saved.

The provider rejected the key or token

The caption reads Alchemy rejected the API key or Coinstash rejected the API token. The credential was valid at some point but isn't accepted now. It may have been revoked, hit a plan limit, or been edited by mistake.

Sign in to your Alchemy or Coinstash account on the web and regenerate the key or token. Paste the new value into Moolah the same way you added the original.

For Coinstash, make sure the token is read-only. Moolah doesn't need trading permissions.

The provider rate-limited the request

The caption reads Alchemy rate-limited. Retry in N min. or its Coinstash equivalent. You've hit the provider's request quota — usually a free-tier limit.

Wait the displayed time and Moolah retries on its own. If you hit the limit often, consider upgrading your plan with the provider, or sync fewer wallets at once.

Network error from the provider

The caption reads Alchemy network error followed by a short detail. The request never reached the provider.

Check your connection. If you're on a VPN or restrictive network, the provider's endpoint may be blocked. Try again once you're back on a normal connection, or select Sync now in the account header to retry.

Malformed response from the provider

The caption reads Alchemy returned a malformed response with a stage in brackets. The request got through but the reply didn't make sense to Moolah. This is on the provider's side.

Select Sync now after a few minutes. If it keeps happening, note the stage name from the caption and report it using the link at the end of this article.

The status says Never synced

The account hasn't completed a successful sync yet. If you added it a moment ago, give it time — the first run can take longer than later updates. If you've waited and nothing's changed, work through the other causes in this article starting with the API key.

If none of the above helped

Report it at github.com/ajsutton/moolah-native/issues with the exact caption from the account header and which provider is involved.
