# Codex Instructions - moolah-native

Read this file before work. For shared assistant rules, also read `guides/AI_ASSISTANT_GUIDE.md`.

## Project Basics

- This is a SwiftUI app for iOS 26+ and macOS 26+.
- Use `just` targets for build, test, formatting, release, and project generation.
- `Moolah.xcodeproj` is generated by `xcodegen` and gitignored. Edit `project.yml`, then run `just generate`.
- Temporary agent output belongs in `.agent-tmp/`.

## Non-Negotiable Review Gate

There is no routine human code review in this repo. Before committing, run the relevant AI reviewer agents and fix every finding immediately, including pre-existing findings. Repeat review and fixes until the relevant reviewers report no findings.

At minimum, run `code-review` after production Swift changes. Add specialized reviewers based on the touched area; see `guides/AI_ASSISTANT_GUIDE.md`.

## Common Commands

```bash
just
just format
just format-check
just test
just test-mac TransactionStoreTests
just build-mac
just build-ios
just generate
```

When running tests, capture output:

```bash
mkdir -p .agent-tmp
just test 2>&1 | tee .agent-tmp/test-output.txt
```

## Codex Skills And Agents

- Repo skills are exposed through `.agents/skills`.
- Codex custom review agents live in `.codex/agents`.
- The Codex review agents are thin wrappers around the detailed review instructions in `.claude/agents/*.md`; read the referenced file before reviewing.
- Codex only spawns subagents when explicitly asked. If review must run before commit, ask for or invoke the relevant review agent explicitly.
