Review recently imported transactions

Confirm or correct what landed in Recently Added before transactions merge into your account lists.

Open Recently Added

  1. In the sidebar, select Recently Added. A badge on the row shows how many transactions are still unreviewed.
  2. The list shows everything that's arrived since you last cleared it, newest first.

Check and correct a row

Each row shows the date, payee, amount, and assigned account and category. Two ways to fix something:

  • Edit inline — select a field on the row to change it in place.
  • Open the detail view — select the row to open it as a full transaction. Adjust any field, then close to save.

If a transaction came in with the wrong sign (an expense shown as positive, for example), edit it here. If you don't want it at all, delete it from the detail view.

Files that need setup

If a CSV had a layout Moolah hasn't seen before, the file lands in a Needs Setup section at the top of Recently Added. Select the row, choose Set up CSV import, pick the target account, and map each column. Moolah remembers the layout for next time. See How CSV import works.

Turn a transaction into a rule

If a transaction came in uncategorised and you'll see more like it, build a rule from it:

  1. On the row, choose Create Rule from Transaction.
  2. Adjust the conditions and actions in the rule editor.
  3. Save the rule. Moolah applies it to future imports.

Build a rule from a search

When you want a rule that matches several transactions at once, search first, then turn the search into a rule:

  1. In Recently Added, type a query into the search field (a payee, a keyword, or part of a description).
  2. In the toolbar, choose Create rule matching this search.
  3. Set the actions you want applied to anything matching that search, and save.

Result

Reviewed transactions move out of the unreviewed badge count and into your account's main transaction list. Any rules you created from here will run on future imports.
