Supported crypto chains and data providers

The chains Moolah can sync a wallet on, and the third-party services that supply on-chain data, exchange data, and prices. All of these calls go from your device directly to the provider — never via a Moolah server.

Supported chains

ChainNative assetBlock explorer
EthereumETHetherscan.io
OP MainnetETHoptimistic.etherscan.io
BaseETHbasescan.org

Not supported

Moolah doesn't sync wallets on Polygon, Arbitrum, Avalanche, or Bitcoin. You can still record holdings on those chains by adding an Investment account in Recorded value mode and entering snapshots manually.

Data providers

ProviderUsed forNotes
AlchemyERC-20 token transfers for crypto walletsRequired. Runs on every sync. Uses your own API key, configured in Settings > Crypto Tokens.
BlockscoutNative and internal ETH activity for crypto walletsRequired. Runs on every sync; it's the authoritative source, so a failure stops the sync. No key needed.
CoinstashExchange account syncUses your own read-only API token, configured per account.
CoinGeckoToken prices, highest priorityOptional. Add a free Demo API key in Settings > Crypto Tokens to use it.
CryptoCompareToken prices, fallbackRequires a free API key for deep price history, configured in Settings > Crypto Tokens.
BinanceToken prices, fallbackNo key needed.
FrankfurterFiat exchange ratesNo key needed.
Yahoo FinanceStock prices and ticker searchNo key needed.
