Set up a watched folder for imports

Point Moolah at a folder so it imports any CSV that lands there. Useful if you regularly drop bank exports into the same place.

Before you start

  • Pick a folder you'll consistently save your CSV exports to. The Downloads folder works, or a dedicated folder you control.
  • On iOS, a folder in iCloud Drive or On My iPhone is fine.

Steps

  1. Open Settings:
    • Mac — press ⌘,.
    • iOS — open the Settings sheet from the sidebar.
  2. Select Import.
  3. Under Folder watch, choose Pick folder.
  4. Select the folder you want Moolah to watch and grant access when prompted.

How scanning works on each platform

The two platforms scan the folder differently:

  • Mac — Moolah watches the folder live. A CSV is imported within seconds of being saved there, even while the app is in the background.
  • iOS — Moolah scans the folder when the app launches and each time you return to it. Files added while the app is in the background are picked up the next time you bring it to the foreground. Live watching is not available on iOS.

Optional: delete CSVs after import

Turn on Delete CSVs after import in the same screen if you want Moolah to remove each file from the folder once it's been imported. The transactions stay in Moolah; only the source file goes. Leave it off if you want to keep the originals.

Stop watching the folder

  1. Return to Settings > Import.
  2. Choose Stop watching.

Moolah forgets the folder, and you can pick a different one if you want.

Result

New CSV files that arrive in the watched folder are imported automatically. They appear in Recently Added for you to review, the same as a manual import.
