Add or edit a transaction

Record a new transaction or change one you've already entered. This is the flow you'll use most often.

Add a new transaction

  1. On a Mac, press ⌘N, or choose File > New Transaction. On iPhone or iPad, open the transaction list and select + in the toolbar.
  2. Pick the account the transaction belongs to.
  3. Choose the Type: Income, Expense, Transfer, Trade, or Custom.
  4. Set the date. New transactions default to today.
  5. Enter the amount. Expenses are usually negative; refunds on an expense are positive.
  6. Start typing the Payee. Moolah autocompletes from payees you've used before.
  7. Pick a Category if you want the transaction to show up in reports under a heading.
  8. Optionally, assign an Earmark so the transaction counts against a bucket you've set aside money for.
  9. Add a Note if you want to remember what it was for.

Moolah saves changes as you make them. There's no separate save button.

Edit an existing transaction

  1. In a transaction list, select the row you want to change.
  2. On a Mac, the inspector on the right shows the transaction. On iPhone or iPad, the detail sheet opens. On a Mac, with the row selected, you can also press ↩ to open the editor.
  3. Change any field. The list updates as you edit.

Edits apply to the one transaction you opened. To shape how future transactions land, set up an import rule instead.

Use the payee autocomplete

As you type into the Payee field, Moolah suggests payees from your past transactions. Picking a suggestion fills the payee in. It doesn't reuse the previous transaction's category or amount — that's up to you.

Change the type with the keyboard

With a transaction open on a Mac, you can switch its type from the keyboard:

  • ⌥⌘1 — Income
  • ⌥⌘2 — Expense
  • ⌥⌘3 — Transfer
  • ⌥⌘4 — Trade
  • ⌥⌘5 — Custom

Result

The transaction appears in the list for its account, updates that account's balance, and feeds into reports, earmark tallies, and sidebar totals.
