Getting started

This section covers your first session with Moolah: installing the app, creating a profile, and choosing what to set up first.

What day one looks like

Moolah doesn't ask you to sign up or create an account. After you install the app and launch it, you land on the Welcome screen and create a profile. A profile is a self-contained set of accounts, transactions, categories, and earmarks. Most people only ever need one.

iCloud sync is optional and starts on its own once iCloud is signed in at the system level — there are no Moolah servers, and nothing to turn on inside the app. If iCloud is off or unavailable, you can still create a profile and use Moolah fully on-device.

What to do first

Once you have a profile, the usual order is:

  • Add the accounts you want to track — bank accounts, credit cards, investments, crypto wallets.
  • Enter recent transactions, or import a CSV from your bank.
  • Set up earmarks for the money you've already mentally set aside (rent, holidays, an emergency fund).

You don't have to do any of this on day one. Moolah is happy to grow as you go.
