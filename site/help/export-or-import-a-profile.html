Export or import a profile as a file

Export saves a profile to a JSON file you keep. Import reads one back in. Use the pair for backups or to move a profile between devices that don't share an iCloud account.

About the file

The file is plain JSON. It contains everything inside the profile: accounts, transactions, earmarks, categories, budgets, schedules, and import rules. It's yours — store it wherever you keep other backups.

Export a profile

On Mac:

  1. Switch to the profile you want to export.
  2. Choose File > Export Profile… or press ⇧⌘E.
  3. Pick a location and select Save.

On iOS:

  1. Open Settings > Profiles.
  2. Swipe the active profile's row and select Export.
  3. Pick a destination in the share sheet (Files, AirDrop, Mail, and so on).

Import a profile

Importing creates a new profile from the file. It doesn't merge into an existing one. If the file holds a profile with the same name as one you already have, Moolah adds it alongside; nothing is overwritten.

On Mac:

  1. Choose File > Import Profile….
  2. Select the JSON file and select Open.

On iOS:

  1. Open Settings.
  2. Select Import Profile.
  3. Pick the JSON file from Files or wherever you saved it.

Result

After export, the JSON file sits in the location you chose. After import, the new profile appears in the profile list and you can switch to it like any other.
