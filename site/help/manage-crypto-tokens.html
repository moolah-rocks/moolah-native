Manage crypto tokens, discovered tokens, and spam

Configure how Moolah prices the tokens in your wallets, review new tokens as they appear, and keep junk off your balances.

Where to find it

Open Settings > Crypto Tokens. The same screen handles three closely-related jobs. You enable on-chain sync, decide which tokens are priced, and deal with unfamiliar tokens that turn up in any wallet's history.

Enable sync with your Alchemy key

Crypto wallet sync needs an Alchemy API key — without one, none of the wallets sync. The key is yours; Moolah queries Alchemy directly from your device.

  1. In the Alchemy section, paste your API key into the API Key field.
  2. Select Save.

To swap in a new key, select Remove, then paste and save the new one. If you don't have a key yet, the section includes a link to Alchemy's pricing page where you can sign up.

Optional: add a CoinGecko key for better pricing

Pricing has fallbacks built in. A free CoinGecko Demo API key promotes CoinGecko to the highest-priority price source, which is usually the best fit for crypto.

  1. In the CoinGecko section, paste your key into the API Key field.
  2. Select Save.

What gets priced: registered tokens

The Registered Tokens list is the set of tokens Moolah prices. Native chain tokens (ETH on Ethereum, OP Mainnet, and Base) are priced automatically. You add other tokens as you want them tracked.

  1. Select + at the top of the Registered Tokens list.
  2. Search by name, symbol, or contract address.
  3. Select the token to register it.

To stop tracking a token, select the ellipsis on its row and choose Remove.

Review what shows up: discovered tokens

When a wallet sync finds tokens you haven't registered, they land in Discovered Tokens rather than being added silently. This is also where airdrops and scam tokens first appear, so it's worth a regular look.

  1. Select Discovered Tokens. The badge on the row shows how many are waiting.
  2. For each token, decide:
    • Approve — Moolah registers the token and starts pricing it. Use this for tokens you actually hold.
    • Mark as Spam — Moolah hides the token from balances and transaction lists. Use this for airdropped junk and scams.

Keep junk out: spam tokens

Tokens marked spam move to Spam Tokens. They no longer appear on balances or in transaction lists. Moolah keeps the record so it doesn't ask you again the next time the same token turns up.

If you marked something as spam by mistake, open Spam Tokens, find the row, and select Approve to move it back into Registered Tokens.

To show spam transactions in lists for a one-off check, on Mac choose View > Show Spam Transactions. On iOS, use the Show Spam toggle in the sidebar.

Result

Your wallets sync against your own Alchemy key. The tokens you care about are priced. New arrivals queue up in Discovered Tokens for review, and scam tokens stay out of your balances.
