Delete a transaction

Remove a transaction you no longer want — a duplicate, a test entry, or one you entered against the wrong account.

Before you start

Deleting a transaction is permanent. Moolah doesn't keep a recoverable copy, and there is no undo. The confirmation dialog says This action cannot be undone for that reason. If the transaction is in the wrong shape, edit it instead — change the account, amount, or type rather than deleting and re-entering.

Steps

  1. In a transaction list, select the row you want to delete.
  2. Trigger the delete action: on a Mac, press ⌫ or select the trash button in the toolbar. On iPhone or iPad, swipe the row from right to left and select Delete.
  3. Confirm in the dialog that appears.

Delete a transfer or a split

A transfer is one transaction with two legs across two accounts. Deleting it removes both legs at once — the source account's outgoing leg and the destination account's incoming leg. A split (a Custom transaction with multiple legs) is also one transaction; deleting it removes every leg together. You don't need to find the other side and delete it separately.

Result

The transaction disappears from the list. The account's balance updates immediately, and any reports, earmark tallies, and sidebar totals recalculate without it.
