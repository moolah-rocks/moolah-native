Add an exchange account

Connect a Coinstash account so your trades auto-import from Coinstash directly to your device.

Before you start

You'll need a read-only API token from your Coinstash account. Create it on Coinstash's website — read-only means Moolah can fetch your trade history but can't move funds or place orders. Follow Coinstash's documentation for the current steps to generate one.

The token is stored in iCloud Keychain on your devices, separate from your Moolah data. If you've turned off iCloud Keychain, the token stays on the device you pasted it on.

Steps

  1. Select + to open the New Account form. (On Mac you can also press ⌃⌘N.)
  2. Choose Exchange for the account type.
  3. Choose Coinstash as the provider.
  4. Enter a Name for the account.
  5. Paste the read-only API token into the API Token field.
  6. Select Create.

Replacing the token later

If you rotate the token on Coinstash, paste the new one in:

  1. Right-click the account in the sidebar (Mac) or open the account and select Edit Account (iOS).
  2. Paste the new token into the New token field.
  3. Select Save.

Result

The exchange account appears under Investments and sync starts automatically. Trades appear in the account view once the first sync finishes.
