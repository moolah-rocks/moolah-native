Profiles

A profile is a self-contained set of finances inside Moolah. Most people only need one, but you can have as many as you like.

What lives inside a profile

Each profile holds its own accounts, transactions, earmarks, categories, and import rules. Nothing crosses from one profile to another. If you keep your household and your side business in separate profiles, they stay separate.

A profile also carries its own default currency and financial-year start month. Set those once when you create the profile, and every report, balance, and total inside it uses them.

When to use more than one

A second profile is useful when the two sets of money shouldn't mingle in any view. Common reasons:

  • Personal finances and a small business.
  • Your own money and a family member's you help manage.
  • A throwaway profile for trying things out without touching your real data.

How profiles move between devices

On a Mac you can open more than one profile window at a time, side by side. To switch, choose File > Open Profile on Mac, or select the profile chip on iPhone or iPad.

If you turn on iCloud sync, your profiles move with you. Open Moolah on a second Apple device signed in to the same iCloud account and your profiles appear there too. Sync is optional; profiles work fully on a single device with no iCloud.

You can also export a profile to a JSON file and import it elsewhere. Use this for backups, or to move data between devices that don't share an iCloud account.
