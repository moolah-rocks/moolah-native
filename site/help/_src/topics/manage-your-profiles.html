Add, switch, edit, or delete a profile

The four things you'll do with profiles after the first one: add another, switch between them, change settings, and tidy up.

Add another profile

On Mac:

  1. Open Settings (press ⌘,).
  2. Select Profiles.
  3. Select + below the profile list.
  4. Enter a name. Adjust the currency and the financial-year start month if you want them different from the defaults.
  5. Select Create Profile.

On iOS:

  1. Open Settings.
  2. Select Add Profile.
  3. Enter a name. Adjust the currency and the financial-year start month if you want them different from the defaults.
  4. Select Create Profile.

The new profile appears in the profile list, ready to open.

Switch profiles

On a Mac, choose File > Open Profile and pick the profile you want. Each profile opens in its own window, so you can keep more than one open at the same time.

On iOS, tap the active profile name at the top of the screen, then choose another from the list.

The selected profile becomes the active one. Its name shows in the window title on Mac, or at the top of the screen on iOS.

Edit a profile's settings

  1. Open Settings > Profiles.
  2. Select the profile you want to change. The detail pane appears.
  3. Edit the Name, Currency, or Financial Year Starts field.

Changes save as you make them. Changing the currency doesn't convert existing balances. It changes the currency used for new totals and reports going forward. Most people set it once and leave it.

The updated values appear immediately in the profile list and in any open windows.

Delete a profile

Deleting a profile removes every account, transaction, earmark, category, and rule inside it. This cannot be undone.

If you sync with iCloud, the deletion propagates to your other Apple devices too. Export the profile first if you want a copy.

  1. Open Settings > Profiles.
  2. Select the profile you want to remove.
  3. On Mac, select − below the profile list. On iOS, swipe the row and select Delete.
  4. Confirm by selecting Delete Profile.

The profile and its data are gone. If it was the active profile, Moolah switches to another one.
