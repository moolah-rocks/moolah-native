Assign a transaction to an earmark

Assign an earmark to a transaction so the money counts against that bucket. The earmark's balance and any budget line items update straight away.

Steps

  1. Open the transaction. On a Mac, select it in the list so it appears in the inspector. On iPhone or iPad, tap it to open the detail sheet.
  2. In the Earmark field, choose the earmark you want this transaction to count against.
  3. Save the transaction. On a Mac the inspector saves as you change fields; on iPhone or iPad, select Done.

Splits across earmarks

A split transaction can target a different earmark on each leg. Change the transaction's Type to Custom, then set the Earmark field on each leg independently. Legs can also be left without an earmark. See Split a transaction across categories for the full split flow.

Removing the assignment

To take a transaction back out of an earmark, open it again and set the Earmark field to None. The earmark's balance updates immediately. The transaction itself stays where it is; only the earmark link goes away.

Result

The earmark's balance reflects the new transaction, and any budget line item that matches the transaction's category shows the spend in its Actual column.
