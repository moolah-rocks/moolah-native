Moolah won't open this profile

You opened a profile and Moolah showed a full-screen Update Moolah to Continue message instead of your data. Here's what that means.

A newer Moolah wrote this profile

This is the only cause. A more recent version of Moolah saved changes in a format this build doesn't know how to read yet. That can happen on another device, or after an update you've since rolled back. Moolah refuses to open the profile rather than risk losing or misreading data.

Your profile isn't corrupted. The data is intact in iCloud (or on disk). This is a guard against a newer file format, not a recovery situation.

Update to the latest Moolah

On the device showing the message, open the App Store and update Moolah. Reopen the app and the profile loads as usual.

If the App Store says Moolah is already up to date, the newer version hasn't shipped to your region yet. App Store updates roll out in phases and may take several days to reach all regions. Check back in the App Store after a day or two.

Or open a different profile

If you have other profiles in this Moolah, you can switch to one of them while you wait to update. Choose File > Open Profile on the Mac, or tap the profile chip on iOS, and pick a profile that this build can read.

If updating didn't help

If the latest App Store build still shows the message, report it at github.com/ajsutton/moolah-native/issues. Include the version number from Moolah > About Moolah and which profile is affected.
