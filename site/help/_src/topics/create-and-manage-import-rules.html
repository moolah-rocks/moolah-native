Create and manage import rules

Rules tell Moolah how to categorise, label, and route transactions as they arrive. Rules run on every import automatically, so you set them up once.

Before you start

Each rule combines four parts: a Name for your reference, a Scope (all accounts or a single account), one or more Conditions that match on description, amount, or source account, and one or more Actions that set the payee, set a category, append a note, mark the transaction as a transfer to an account, or skip the row.

  • Mac — rules live in Settings > Rules.
  • iOS — rules live in Settings > Import Rules.

The screen lists every rule in the active profile, in the order they run.

Create a rule

  1. Open Settings > Rules (Mac) or Settings > Import Rules (iOS).
  2. Select + to add a new rule.
  3. Give the rule a name.
  4. Set the scope to All accounts or pick a single account.
  5. Add one or more conditions. Choose the field, the comparison, and the value to match.
  6. If you have more than one condition, choose Match any or Match all.
  7. Add one or more actions. For example: set the category to Groceries and set the payee to Corner Store.
  8. Review the live preview. It shows how many existing transactions would have matched this rule.
  9. Optional: if the count looks wrong (zero, or far higher than you expect), adjust the conditions and check again.
  10. Save the rule.

Edit or remove a rule

  • Edit — select the rule in the list and adjust any field. Changes apply to future imports, not retroactively.
  • Delete — swipe the rule on iOS, or use the context menu on Mac. Removing a rule doesn't change transactions it already touched.

Build a rule from a transaction

If you've already got a transaction that ought to have been categorised automatically, you can build a rule from it without opening Settings. In Recently Added, select Create Rule from Transaction on the row. Moolah pre-fills the conditions from that transaction; you pick the actions and save. See Review recently imported transactions.

Result

Saved rules apply automatically the next time a CSV is imported. Imported transactions that match a rule arrive in Recently Added with the payee, category, note, or transfer already set.
