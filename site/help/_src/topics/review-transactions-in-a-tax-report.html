Review transactions in a tax report

Open a tax total to see every transaction included in it, then correct any details that need changing.

Open the tax report

  1. In the sidebar, select Reports.
  2. Select Tax.
  3. Choose a Financial Year.

Review a total

  1. Under Taxable income and deductions, select the Taxable income or Deductions total.
  2. Review the transactions and the running balance. The final balance matches the total you selected.
  3. Select a transaction to open its inspector on Mac or its detail sheet on iPhone and iPad.
  4. Change the Category, Amount, or other details that need correcting. Moolah saves the transaction as you edit.

Read owner-specific amounts

When a transaction belongs to more than one tax owner, the list shows only the selected owner's share. The two-person icon beside the amount marks it as a share, not the transaction's full value.

The running balance also uses the selected owner's shares. For All owners, Moolah combines the shares and shows each transaction's full tax value.

Result

The transaction list and tax report update with your changes, so the balance and the original total stay aligned.
