CSV import dropped into Needs Setup

You imported a CSV file and it landed in Needs Setup instead of your transaction list. Here's what that means and how to clear it.

Moolah doesn't recognise this file shape yet

The auto-detector matches CSV files against shapes it already knows — header signatures, delimiters, date formats. Your file doesn't match a known shape, so Moolah needs you to map the columns once. Future files with the same shape import without setup.

Set it up

  1. Open Recently Added in the sidebar.
  2. In Recently Added, select the Needs Setup section, then select the row for this file.
  3. Select Set up CSV import.
  4. Pick the target account for these transactions.
  5. Map the file's columns to Date, Description, Amount, and (optionally) Payee.
  6. Confirm. The transactions move into your account.

What happens next time

Moolah remembers the shape you set up. The next CSV with the same headers and column order imports without asking — even files from the same source you'll add later.

To remove a learned shape

If you set up a shape by mistake, open Settings > Import. Swipe the profile row and choose Delete. The next import of that shape will land in Needs Setup again.

If the setup screen won't accept your file

Make sure the file is a real CSV — comma- or tab-separated, with one transaction per row. If the file looks right and setup still refuses, report it at github.com/ajsutton/moolah-native/issues with a sample.
