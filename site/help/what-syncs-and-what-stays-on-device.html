What Moolah syncs

This reference lists what optional iCloud sync moves between your devices, what stays on each device, and where exchange API tokens fit in.

Synced through CloudKit

When iCloud sync is on, your profile data moves between your devices through Apple's CloudKit, end-to-end encrypted by iCloud.

TypeWhat it covers
ProfilesEach profile's name, default currency, and financial-year start.
AccountsEvery account in every profile, including hidden flags.
Transactions and legsAll transactions, including split legs and trade legs.
CategoriesYour category tree, including parent and child relationships.
EarmarksEarmarks, their savings goals, and hidden flags.
Budget itemsPer-category budget lines inside earmarks.
Account groupsThe groupings you've arranged accounts into.
Investment value snapshotsThe values you've recorded for investment accounts over time.
Recurring & scheduled transactionsThe recurrence and scheduling set on a transaction.
Transfer suggestionsThe pending "Merge as Transfer" pairs Moolah has spotted.
Import profilesThe CSV shapes you've set up.
Import rulesThe auto-categorise and auto-assign rules you've created.

Stored in iCloud Keychain

Exchange API tokens are kept in iCloud Keychain, Apple's encrypted store for secrets. This is separate from CloudKit. iCloud Keychain syncs the token across your devices so you don't have to paste it on each one. The token still lives separately from your profile data.

Your price-provider API keys — your Alchemy key and optional CoinGecko key — are kept in iCloud Keychain the same way, so you only enter them once and they follow you to your other devices.

Stays on each device

Some things are specific to a device and don't follow you around. Each device keeps its own copy.

TypeWhy it's device-local
Exchange-rate cacheRebuilt on demand from rate providers.
Crypto and exchange sync stateLast-synced timestamp and last-error state for each synced account.
Watched-folder settingsThe folder bookmark is specific to the device's file system.
Active profileWhich profile is currently open in this app.
View stateSidebar selection, sort order, and other UI preferences.

Third-party calls

Crypto wallet and exchange syncs are not part of iCloud sync. Those calls go from your device directly to the relevant provider — Alchemy, Blockscout, CoinGecko, or Coinstash — using the keys and tokens you've supplied. For the full picture, see Sync and privacy.
