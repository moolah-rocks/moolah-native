Add an account

Create a new account so you can record transactions against it.

Before you start

  • Decide which of the six account types you need — the type drives what fields appear next, and you can't change it later.
  • For a crypto wallet, have the 0x address ready.
  • For an exchange account, have a read-only Coinstash API token ready.

Steps

  1. In the sidebar, select New Account. On Mac you can also press ⌃⌘N.
  2. Choose an account type from the picker.
  3. Enter a Name you'll recognise in the sidebar.
  4. Pick the account's Currency. The default is your profile currency.
  5. Enter the Opening Balance and Opening Date. Moolah records a system-generated opening transaction so the running balance lines up.
  6. Fill in any type-specific fields for your account type.
  7. Select Create.

Type-specific fields

Credit Card

Enter the balance you owe as a negative number. A balance of 1,200 owing is entered as -1200. Credit card debt is negative; a refund on a credit card appears as a positive expense — this is correct behaviour.

Asset

Use Asset for things like a car, a property, or a collectible. The opening balance is your current estimate of its value. You can update the value over time by recording transactions.

Investment

Pick a Valuation mode. Recorded value means you'll add balance snapshots yourself. Calculated from trades means you'll record buys and sells, and Moolah will work out the current value at market prices. You can switch modes later. See Add an investment account for the full walkthrough.

Crypto Wallet

Pick a Chain: Ethereum, OP Mainnet, or Base. Paste the wallet's 0x address. ENS names aren't supported — paste the 0x address directly. Transaction import runs after you add an Alchemy API key in Settings > Crypto Tokens.

Exchange

Pick Coinstash as the provider. Create a read-only API token inside your Coinstash account, then paste it here. Moolah stores the token in iCloud Keychain and begins importing trades.

Result

The new account appears in the sidebar, under Current Accounts or Investments depending on its type. Crypto wallets and exchange accounts begin their first import straight away.
