Create an earmark

Set up a new earmark to reserve part of your money for a specific purpose, optionally with a savings goal to track progress.

Before you start

  • You need at least one account in the profile. If you haven't added one yet, see Add an account.

Steps

  1. Open the New Earmark sheet. On a Mac, press ⇧⌘N or choose File > New Earmark…. On iPhone or iPad, open the sidebar and select + in the Earmarks section.
  2. In the Name field, enter a name that describes what the money's for — for example, "Holiday" or "Quarterly tax".
  3. (Optional) Change the Currency. Earmarks default to your profile's currency.
  4. (Optional) In the Savings Goal section, enter the target Amount. Leave it blank if you want a bucket without a target.
  5. (Optional) Turn on Set Date Range to add a start and end date for the goal. The detail view then shows how much time you have left, or marks the goal as past due once the end date passes.
  6. Select Create.

Result

The new earmark appears in the Earmarks section of the sidebar with a zero balance. The sidebar's Available Funds total also appears now that you have at least one earmark. If you set a savings goal, the earmark's detail view shows a progress bar against that target.

To put money in the earmark, assign transactions to it as they come in. If you'd rather break the earmark down by category, open it and select the Budget tab. You can change the name, savings goal, or hidden state any time from Edit Earmark.
