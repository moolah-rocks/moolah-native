Importing data

Moolah imports transactions from CSV files you bring in yourself. There is no bank-feed API, and no connection to your bank. This article gives an overview. For step-by-step instructions, pick a topic below.

How importing works

You export a CSV from your bank, brokerage, or another finance app, then hand it to Moolah. The app reads the file, parses the rows into transactions, and lands them in your accounts. After the first time you set up a particular file shape, Moolah recognises future files of the same shape and imports them without asking again.

Imported transactions don't go straight into your usual lists. They first appear in Recently Added, where you can review them before they merge into the main flow.

Ways to bring a file in

Moolah accepts CSV files through several routes:

  • File menu — File > Import CSV on Mac, or the share sheet on iOS.
  • Drag and drop — drop a file on the Moolah window, or directly on an account in the sidebar to pre-select it.
  • Paste — copy tabular text from a webpage or spreadsheet, then choose File > Paste CSV on Mac.
  • Watched folder — point Moolah at a folder and any CSV that lands there gets imported.

Import rules

Import rules match transactions by payee, description, or amount, and apply a category, an earmark, or an account assignment. Rules run on every import, so once you've taught Moolah that "WOOLWORTHS" is groceries, you don't have to do it again.
