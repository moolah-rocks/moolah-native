Try Moolah without committing real data

If you want to explore Moolah before recording your actual finances, create a throwaway profile and delete it when you're done. A second profile is fully isolated — anything you do inside it won't affect your real accounts. Moolah doesn't ship with sample data, so you make your own.

Steps

  1. On Mac, press ⌘,. On iPhone or iPad, open Settings from the sidebar.
  2. Go to Profiles and select + to add a profile.
  3. Name it something obvious like Sandbox and select Create Profile.
  4. Switch to the new profile. On Mac, choose File > Open Profile > Sandbox. On iPhone or iPad, select the profile from the sidebar.
  5. Add some accounts and transactions to explore — try a transfer, an earmark, or a report.
  6. When you're done, switch back to your real profile so you don't accidentally delete the wrong one.
  7. In Settings > Profiles, select the sandbox profile.
  8. Select − (Mac) or swipe and choose Delete (iPhone or iPad), then confirm.

Result

The sandbox profile and everything inside it is gone. Your real profile is unchanged.
