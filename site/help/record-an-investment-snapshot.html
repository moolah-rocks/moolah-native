Record an investment value snapshot

Record the current value of a Recorded-value investment account whenever you check the balance.

Before you start

This article applies to investment accounts set to Recorded value. If your account is set to Calculated from trades, record your activity as trades instead — see Record a trade.

You don't need a snapshot every day or even every week — whenever you check the account is enough.

Steps

  1. Open the investment account from the sidebar.
  2. Select Record Value (or + in the toolbar).
  3. Enter the Date the value applies to. The default is today, but you can back-date a snapshot to the statement date.
  4. Enter the Value in the account's currency.
  5. Select Save.

How snapshots show up

Each snapshot appears in the account's values list, newest at the top. The net worth graph holds the value steady between snapshots and steps to the new value on the date you recorded it. Recording occasional snapshots is enough to keep the graph honest.

Editing or removing a snapshot

To remove a snapshot, swipe its row in the values list (iOS) or right-click and select Delete (Mac). To change a value or its date, delete the snapshot and record a fresh one.

Result

The new snapshot appears in the account's values list and shapes the net worth graph between recordings. The account's contribution to the Investment Total updates to the latest value.
