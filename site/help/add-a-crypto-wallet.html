Add a crypto wallet account

Set up an on-chain crypto wallet account that auto-imports transactions from Alchemy directly to your device.

Before you start

You'll need two things:

  • The wallet's 0x address. ENS names aren't supported — paste the address itself.
  • An Alchemy API key. You create the key in your own Alchemy account. It stays on your device — Moolah uses it to call Alchemy directly, with no Moolah servers in between. If you don't have a key yet, add the wallet first and configure the key after. Sync starts once the key is in place. See Manage crypto tokens, discovered tokens, and spam.

Steps

  1. Select + to open the New Account form. (On Mac you can also press ⌃⌘N.)
  2. Choose Crypto Wallet for the account type.
  3. Enter a Name for the account.
  4. Choose the Chain: Ethereum, OP Mainnet, or Base.
  5. Paste the wallet's 0x address.
  6. Select Create.

First sync

Once your Alchemy key is in place, sync starts automatically. A sync-status bar at the top of the account view shows the last sync, any current attempt, and inline messages if something needs attention.

The first sync can take a minute or two on a busy address. Select Sync now to trigger another run.

Block-explorer link and counterparty addresses

Each imported transaction includes a block-explorer link that opens the transaction on Etherscan, Optimistic Etherscan, or Basescan, depending on the chain. The transaction also lists the counterparty addresses for each leg.

These are read-only and copy-only. Selecting a counterparty address copies it to the clipboard rather than opening a link. The deliberate friction lets you verify the address yourself before pasting it somewhere that matters.

Result

The wallet appears in the sidebar under Investments. Once the first sync finishes, the account view lists your on-chain transactions and shows current positions.
