Filter and search transactions

Narrow a long transaction list down to what you're looking for by typing into the search field, by applying filters, or by combining both.

Search by text

  1. Open the transaction list you want to search.
  2. On a Mac, press ⌘F to focus the search field. On iPhone or iPad, scroll to the top of the list and use the search field there.
  3. Type any text. Moolah matches against payee, note, and category as you type.

Apply filters

  1. In the toolbar, select Filter to open the Filter Transactions sheet.
  2. Set any of the filters you want:
    • Account — limit to a single account, or all accounts.
    • Earmark — show only transactions assigned to a particular earmark.
    • Categories — pick one or more categories.
    • Payee — match a specific payee.
    • Schedule — include or exclude scheduled transactions.
    • Date range — restrict to a period.
  3. Close the sheet. The active filters appear above the list so you can see what's applied.

Combine search and filters

Search text and filters compose. Set Account to your everyday spending account, set a date range of last month, and type "coffee". Moolah shows last month's coffee runs from that one account.

Clear what you've set

To clear the search, empty the search field. To clear filters, open the filter sheet and reset the fields you set, or use the clear control above the list.

Result

The transaction list shows only the rows that match every active filter and the search text. The list returns to the full set when you clear them.
