Turn on iCloud sync

This article walks through getting optional iCloud sync working so your profiles move between your Apple devices. There's nothing to flip on inside Moolah — sync uses your own iCloud, end-to-end encrypted by iCloud, and starts automatically once iCloud is available.

Before you start

  • Make sure each device is signed in to iCloud at the system level, with the same Apple ID.
  • Install Moolah on each device from the App Store.

Steps

  1. On each device, open System Settings (Mac) or Settings (iPhone, iPad).
  2. Confirm you're signed in to iCloud with the same Apple ID on every device.
  3. Launch Moolah. The Welcome screen shows what it found in iCloud — for example, Found data on iCloud · N records downloaded or No profiles in iCloud yet.
  4. If you see an iCloud-off message instead, select Open System Settings from the Welcome screen. See iCloud says it's off for the four reasons iCloud can be unavailable.
  5. Sign in to iCloud, then return to Moolah.
  6. Once iCloud is on, check the sync status footer in the sidebar. It shows the last successful sync or the current activity.

Result

Your profiles sync between your devices automatically. The first sync after a fresh install can take a moment as data downloads from iCloud. To open a profile that was created on another device, see Pick up a profile on another device.
